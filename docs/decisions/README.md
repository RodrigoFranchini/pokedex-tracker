# Decision records

One file per decision that shaped the app, in the order they were made. Each
records the **context** it was made in, the **decision** itself, and the
**consequences** — including the ones that cost something.

These are the settled decisions. Do not undo one without being asked, and if you
do, add a new record superseding it rather than editing the old one. A record
that turned out to be wrong is more useful than a record that was quietly
rewritten.

## Format

Short, and in this shape:

```markdown
# NNNN — Title

**Status:** Accepted | Superseded by NNNN
**Date:** YYYY-MM

## Context
What was true that forced a choice.

## Decision
What was chosen, stated plainly.

## Consequences
What this buys, and what it costs. Both.
```

Alternatives get their own section when the one not taken is the obvious
question a reader will have.
